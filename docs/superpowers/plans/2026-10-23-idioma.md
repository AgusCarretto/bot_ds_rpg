# Idioma (español / inglés, `/language`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que el bot se pueda jugar en español o en inglés, con el idioma de Discord por defecto y `/language` (y `aa language`) para cambiarlo, traduciendo primero las pantallas más usadas.

**Architecture:** una clase estática `Loc` (`GameData/Loc.cs`) con el idioma actual en un `AsyncLocal` fijado una vez por comando; `Loc.T("texto en español")` y `Loc.F($"…")` buscan la plantilla en `Locales/en.json` (incrustado) y caen al español si falta. El idioma de cada jugador vive en una tabla aparte que nunca rompe nada si falta. Una herramienta (`tools/loc`) y un arnés (`loctest`) vigilan que el catálogo y el código no se separen.

**Tech Stack:** C# / .NET 10, Discord.Net 3.20.1 (`interaction.UserLocale`), Dapper/Npgsql, arneses de consola en `tests/`.

**Spec:** `docs/superpowers/specs/2026-10-23-idioma-design.md` (leerlo antes: decisiones, alcance y límites).

## Global Constraints

- Solo español e inglés; nada pensado para un tercer idioma.
- Los **nombres** de ítems, monstruos, zonas, personajes, clases y títulos **no se traducen**. Nunca se traducen: `custom id`, nombres de comandos, valores de opciones, claves de la base.
- Con el idioma en español la salida es **idéntica** a la de hoy: los arneses viejos pasan sin cambios (salvo que un texto se haya cambiado a propósito).
- Todo falla hacia español: catálogo que no carga, plantilla ausente, `{0}` de más, tabla de idioma inexistente. Un comando nunca se rompe por el idioma.
- La migración `Database/add_language.sql` es **opcional** antes del binario (re-corrible, `IF NOT EXISTS`); `schema.sql` la trae.
- Una llamada `Loc.T`/`Loc.F` lleva **un solo literal** (o literales unidos con `+`); si no, el escáner la marca.
- Límites de Discord: descripción de comando ≤ 100 caracteres, embed ≤ 6.000, campo ≤ 1.024.
- Convenciones del repo: un arnés = `tests/<nombre>/<nombre>.csproj` (`<Project Sdk="Microsoft.NET.Sdk"></Project>`) + `Program.cs` que imprime `[OK]`/`[FALLA]` y termina en `TODO OK`; comentarios y textos en español rioplatense; después de cada cambio `dotnet build` y `bash tests/run-all.sh <arnés…>`; la suite completa (`bash tests/run-all.sh`, solo contra la base LOCAL) al final de cada tarea de pantallas.
- Flujo de git: trabajar en el worktree `bot_ds_rpg_wip` en una rama nueva desde `develop`; los commits terminan con `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; al terminar un bloque, avanzar `develop` en `bot_ds_rpg` con `merge --ff-only` y `git push origin develop`. **`main` solo con el OK explícito del dueño.**

## Decisiones del plan (no cambian el spec)

- Además de `Loc.T`/`Loc.F` hay dos ayudas para texto que vive en tablas estáticas (diálogos, descripciones de misiones y de clases): `Loc.Mark("literal")` (devuelve el literal tal cual; el escáner lo toma como clave del catálogo) en el lugar donde se declara, y `Loc.Tr(textoEnTiempoDeEjecución)` donde se muestra (busca ese texto en el catálogo). Las tablas `static readonly` que hoy se arman una vez no sirven con un idioma por comando: las que se traducen pasan a ser propiedades (`static string[] X => [...]`).
- Plurales: dos `Loc.T` elegidos con un ternario, sin sistema general.

## Review Focus

1. Dos jugadores a la vez en idiomas distintos no se pisan el idioma (`AsyncLocal` con comandos concurrentes) → test en Task 1.
2. Una plantilla con `$"…"` que lleva ternarios, llamadas con comas o llaves escapadas se numera igual que el compilador → test del escáner en Task 6.
3. Un embed en inglés se pasa de 6.000 o de 1.024 por campo → revisión de tamaño en cada pantalla (`LeakCheck.FitsDiscord`, Task 7).
4. Un texto en inglés que pide teclear algo (`aa enchant weapon`, `aa chop advanced`) y el comando no lo entiende → Task 14 y el chequeo «todo `aa …` nombrado en inglés existe» de Task 6.
5. Una pantalla traducida deja caer español adentro (frases de monstruo, errores, cooldowns) → `LeakCheck.NoSpanish` en cada pantalla.
6. Un jugador sin idioma guardado, con locale raro (`pt-BR`, vacío) o con la tabla sin crear → Task 3.

  ```csharp
    public static string Current { get; }                    // AsyncLocal, "es" por defecto
    public static string Normalize(string? language);        // "en"/"EN"/"english" -> "en"; cualquier otra cosa -> "es"
    public static IDisposable Use(string language);          // fija y restaura al cerrar (anidable)
    public static string T(string es);                       // texto simple
    public static string F(FormattableString es);            // plantilla = es.Format, datos = es.GetArguments()

    public static string Tr(string esRuntime);               // traduce un texto ya declarado con Mark

    public static void LoadEmbedded();                       // lee Locales.en.json una vez; nunca tira
  }
  ```
